## 🏪 Pharmacy

**Descrição:**

## ⚙️ Scheduler

**Descrição:**
Um simulador de **algoritmos de escalonamento de processos**, desenvolvido em **Java** com **Swing** para a interface gráfica.
O projeto tem como objetivo demonstrar, de forma visual e prática, como diferentes algoritmos de escalonamento organizam e executam processos dentro de uma CPU.

**Algoritmos implementados:**

* **FCFS (First Come, First Served)** → Executa processos na ordem de chegada.
* **SJF (Shortest Job First)** → Dá prioridade ao processo com menor número de instruções.
* **RR (Round Robin)** → Executa os processos em ciclos, respeitando um quantum definido.

A interface mostra processos representados por **cubos coloridos**:

* 🔵 Azul → processo em execução;
* 🟥 Vermelho → processo pendente;
* 🟩 Verde → processo finalizado.
