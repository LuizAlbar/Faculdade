## ⚙️ Scheduler

**Descrição:**
Simulador de **algoritmos de escalonamento de processos**, desenvolvido em **Java** com interface gráfica **Swing**.
O projeto demonstra de forma visual como diferentes algoritmos de escalonamento organizam e executam processos dentro de uma CPU.

**Algoritmos implementados:**

* **FCFS (First Come, First Served)** → Executa os processos na ordem de chegada.
* **SJF (Shortest Job First)** → Prioriza o processo com menor número de instruções.
* **RR (Round Robin)** → Executa os processos em ciclos, respeitando um quantum definido pelo usuário.

**Representação visual na interface:**

* 🔵 Azul → processo em execução
* 🟥 Vermelho → processo pendente
* 🟩 Verde → processo finalizado
